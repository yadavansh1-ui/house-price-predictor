# House Price Prediction System using Machine Learning

## Problem Statement

There are many factors that decide the price of a house such as area, number of bedrooms and age of the house. Most people cannot estimate whether a given price is reasonable or overpriced. There should be a simple tool that can predict the price based on basic property details.

## Scope of the Project

The system predicts the approximate price of a house by taking three inputs: Area (sq ft), Bedrooms and Age of the house. It trains a machine learning model using a dataset and then allows the user to predict prices anytime. Visual comparison and model performance are also shown.

## Target Users

People planning to buy or sell houses, real estate beginners, students learning machine learning and anybody who wants a rough price estimate without manual calculation.

## High-Level Features

* Train a Linear Regression model on the given dataset
* Predict house price based on user input
* Show model accuracy score
* Graph of actual vs predicted values
* Simple menu-based interface
